Text, Background & Border Styling

Learn how to use CSS to style text, backgrounds, and borders with practical examples

Text Styling

Text Properties

CSS provides numerous properties to style text:

Colored and bold text
Monospace font family
Underlined text
Uppercase with letter spacing
Text with shadow effect

CSS Code Example

p {
    color: #2c3e50;
    font-family: 'Arial', sans-serif;
    font-size: 16px;
    line-height: 1.6;
    text-align: justify;
    text-transform: none;
}

Background Styling

Background Properties

CSS allows various background customizations:

Solid color background
Gradient background
Image background (placeholder)

CSS Code Example

.element {
    background-color: #3498db;
    background-image: url('image.jpg');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}

/* Shorthand */
.element {
    background: #3498db url('image.jpg') center/cover no-repeat;
}

Border Styling

Border Properties

CSS offers multiple ways to style borders:

Solid border
Dashed border
Double border
Rounded dotted border

CSS Code Example

.element {
    border-width: 2px;
    border-style: solid;
    border-color: #3498db;
    border-radius: 8px;
}

/* Shorthand */
.element {
    border: 2px solid #3498db;
    border-radius: 8px;
}
